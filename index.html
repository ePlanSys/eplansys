ePlanSys — Epistemic Planning System for ROS2

[](LICENSE)

ROS2 Epistemic Planning System (eplansys in short) is a project whose objective is to provide Robotics developers with a reliable, simple, and efficient EPDDL-based planning system with Dynamic Epistemic Logic reasoning. It is implemented in ROS2 and built on top of PlanSys2.

This project is the result of research on epistemic planning for autonomous multi-robot systems. PlanSys2 greatly inspired this project. In addition to epistemic extensions, we contribute key new aspects: S5/KD45 world models, EPDDL domain support, and heuristic search over epistemic states.

We hope that this software helps to include formal epistemic reasoning in more Robotics projects, offering a practical bridge between DEL theory and ROS2 deployment.

We want to invite you to contribute to this Open Source project!
