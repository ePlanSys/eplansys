Tutorials
=========

These tutorials use the grounded tasks checked into
``plansys2_epistemic_planner/test/tasks``, so they can be followed without an
EPDDL toolchain. They assume a workspace built and sourced as described in
:doc:`../getting_started/installation`.

The classical PlanSys2 tutorials, which cover the terminal, the domain and
problem experts, and writing action performers, are on the `PlanSys2 web page
<https://plansys2.github.io>`_ and apply unchanged here.
