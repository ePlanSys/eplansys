# Front-page tutorial video

`_static/video/eplansys-tutorial.mp4` (1280×720, 30 fps, 66 s, no audio) and
its poster frame are generated by the two scripts in this directory. Nothing in
the video is drawn by hand: the Kripke models come from the grounded task, and
the planner lines are the output of the pinned planner.

## Inputs

1. Ground the survey mission with plank:

   ```bash
   plank export -d eplansys_demo/epddl/survey-team.epddl \
                -p eplansys_demo/epddl/survey-team-problem.epddl \
                -l plansys2_epddl_grounder/libraries/intermediate.epddl \
                -o /tmp/survey
   ```

2. Solve it with the planner at the revision `dependency_repos.repos` pins
   (314bc29 at the time of rendering):

   ```bash
   epistemic_planner --task /tmp/survey/survey-team-problem.json \
                     --plan /tmp/survey/plan.json --strategy aostar
   ```

   Output used in scene 3: `Loaded: 4 atoms, 3 agents, 2 worlds (2 designated),
   30 actions`; `Solution found at depth 3  Expanded=20  Generated=26`;
   `validator OK — 2 leaves, 4 branches checked`. The policy is
   goto-site scout → scan scout → relay-{dirty,clean} scout→relay.

## Models

`del.py` applies the DEL product update to the grounded task along three
branches (the policy with each scan outcome, and the broadcast counterfactual),
contracts each result to its bisimulation quotient, and evaluates the goal
conjuncts:

```bash
python3 del.py /tmp/survey/survey-team-problem.json traces.json
```

```
policy-dirty
  None                         2 worlds, 2 designated  goal=[False, False, True]
  goto-site_scout              2 worlds, 2 designated  goal=[False, False, True]
  scan_scout                   2 worlds, 1 designated  goal=[True, False, True]
  relay-dirty_scout_relay      3 worlds, 1 designated  goal=[True, True, True]
broadcast
  ...
  broadcast-dirty_scout        1 worlds, 1 designated  goal=[True, True, False]
```

These counts agree with the `epistemic_state` log in the survey demo.

## Rendering

Requires pycairo, ffmpeg with libx264, and the Noto Sans, DejaVu Sans,
DejaVu Sans Mono and DejaVu Serif fonts. Run from this directory:

```bash
python3 render.py ../_static/video/eplansys-tutorial.mp4
```

The poster frame (scene 6, after the private announcement) is written next to
the video. If the planner pin changes, re-run the inputs and update
`PLANNER_LINES` in `render.py`.
