Detailed Description

Whether a failed mission is worth planning again.

Kept apart from the loop that talks to the planner and the executor so the decision can be tested without a running system, the way the executor's own replan guard is.

Two bounds, and they answer different questions. max_attempts is a budget: how many plans the mission may ask for in all. The progress bound is what tells a recoverable failure from a permanent one: an attempt in which some action completed has moved the mission, and replanning from where it got to is a different question from the last one; an attempt in which nothing completed asks the planner the same question again, and a planner that answered it the same way last time will do so again.
